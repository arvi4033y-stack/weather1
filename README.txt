WEATHER APP PROJECT

Files:
- index.html: Page structure
- style.css: Design and responsive layout
- script.js: Fetches weather data and updates the page

HOW TO RUN:
1. Extract weather-project.zip.
2. Open the extracted folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Make sure you have an internet connection.
5. Search for a city such as Kurnool, Hyderabad, or London.

API:
This project uses Open-Meteo geocoding and forecast APIs. No API key is required.
Internet access is required for live weather data.
